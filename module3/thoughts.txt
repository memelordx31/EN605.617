Since in my other class, Building and Training Large Language Models, we are dealing with transformers which mostly consist of matrix dot products, I tried implementing a matrix multiplication function for this assignment. I run both the GPU and Host kernels 10 times each to capture statistics and found that in every run the GPU was able to complete the operation in microseconds while the Host took minutes. This showed me mechanically what makes GPUs so much better suited for AI/ML related workloads than CPUs.
